# 🪄 piros-spellbook

Personal AI-agent skills — spells my agents can cast.

## Install

With the [skills CLI](https://skills.addy.ie):

    npx skills add Piras2024/piros-spellbook

Pick the skills you want; they land in `~/.agents/skills/` and are
picked up by Kilo (and other agents) on the next session.

## Skills

| Skill | What it does |
|---|---|
| `html-report` | Renders analyses/findings as self-contained dark-theme HTML reports |
